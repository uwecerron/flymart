This directory contains the upstream browser runtime, connectome binary, and
visual assets required to execute the project. FlyMart removes only the
optional caretaker server UI scripts from index.html because that Node/SQLite
service is not part of the browser simulation and is not deployed here.
The connectome simulation, Web Worker, behavior model, rendering, controls,
and FlyWire-derived runtime data are upstream code at the pinned commit.
Visible em dash punctuation was changed to colons to match FlyMart copy style.

FlyMart fm2 presentation changes: responsive toolbar, optional brain stats,
interaction hint, 1.7x initial camera zoom and camera follow. Camera centering
no longer teleports the animal. Neural worker, connectome data, sensory inputs
and behavior model are unchanged. See css/flymart.css and js/flymart.js.

fm3: Blender-created mesh and Three.js WebGL presentation adapter.
Renderer reads upstream position, heading, food and light; does not advance
or modify brain state. Original Canvas renderer remains the fallback.
